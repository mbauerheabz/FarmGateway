# FarmGateway

FarmGateway enables real-time data processing and auto-scaling clusters as a central data hub.

The key benefits of using FarmGateway include:

- FarmGateway enables real-time data processing
- and auto-scaling clusters as a
- central data hub

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/FarmGateway.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

FarmGateway is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
